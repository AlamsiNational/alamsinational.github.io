# alamsinational.github.io

This site exists for one purpose: it hosts the **public** half of the key pair that identifies Zero's
read-only Tesla Fleet API app to Tesla, at the path Tesla requires:

`/.well-known/appspecific/com.tesla.3p.public-key.pem`

A public key is meant to be public. Nothing secret lives here: no private key, token, password, location
or personal data. The private key never leaves the owner's computer.
